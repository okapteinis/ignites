# Ignites WordPress Theme

A modern, clean and professional WordPress theme with Gutenberg support.

- **Ojārs Kapteinis** (https://github.com/okapteinis/)

## Features

- ✅ PHP 8.4 compatible
- ✅ Bootstrap 5.3.8 support
- ✅ Gutenberg block editor compatible
- ✅ Latvian translation (lv_LV)
- ✅ Responsive design
- ✅ Custom background and colors
- ✅ Widget areas
- ✅ Translation ready
- ✅ Custom menu support
- ✅ Featured images support

## Installation

1. Download the theme from GitHub
2. Upload to WordPress: Appearance > Themes > Add New > Upload Theme
3. Activate the theme
4. Configure in Appearance > Customize

## Languages

- **English** (default)
- **Latvian** (lv_LV)

### To use Latvian translation:

1. Go to Settings > General
2. Set Site Language to "Latviešu"
3. Save changes

## Recommended Plugins
