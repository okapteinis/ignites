# Changelog

All notable changes to the Ignites theme will be documented in this file.

## [1.1.1] - 2025-11-11

### Fixed
- Linearicons font file paths corrected in CSS
- Scroll-to-top button icon now displays correctly (fixed EB14 box issue)
- Latvian translation files now load properly
- Text domain moved to 'init' hook for WordPress 6.7+ compatibility

### Changed
- Updated theme header in style.css with new maintainer info
- Theme URI changed to GitHub repository
- Author updated to Ojārs Kapteinis
- Added Domain Path for translations

## [1.1.0] - 2025-11-11

### Added
- PHP 8.4 full compatibility
- Bootstrap 5.3.8 support (upgraded from Bootstrap 4)
- Complete Latvian language translation (lv_LV.po and lv_LV.mo)

### Changed
- All Bootstrap 4 class names migrated to Bootstrap 5 equivalents
- Data attributes updated to data-bs-* format
- jQuery dependency removed from Bootstrap components
- Popper.js updated to v2
- Improved responsive design

### Removed
- Deprecated Bootstrap 4 components (jumbotron, media, form-row)
- jQuery dependencies

## [1.0.0] - Original Release

- Initial fork from f4h3m/ignites
- Gutenberg compatible WordPress theme
